# AgriShield

AI-Powered Heavy Metal Risk Assessment and Decision Support System for Safe Crop Cultivation.

## Overview

AgriShield is a web-based decision support system designed to assess heavy metal contamination in agricultural soil and assist users in making informed crop cultivation decisions.

## Key Features

- Heavy metal contamination assessment
- Pollution indices calculation
- Crop-specific bioavailability analysis
- Food safety assessment
- Human health risk assessment
- Crop suitability classification
- AI-powered recommendations using Google Gemini API
- Interactive dashboard
- CSV-based data analysis

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Python
- FastAPI
- Google Gemini API
- CSV / JSON

## Pollution Indices

- Contamination Factor (CF)
- Geo-accumulation Index (Igeo)
- Enrichment Factor (EF)
- Pollution Load Index (PLI)
- Nemerow Pollution Index (NPI)
- Potential Ecological Risk Index (PERI)

## Health Risk Assessment

- Average Daily Intake (ADI)
- Hazard Quotient (HQ)
- Hazard Index (HI)
